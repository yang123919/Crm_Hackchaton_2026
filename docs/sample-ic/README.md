# Sample IC for testing the scanner

`sample_mykad_FAKE.png` is a drawn card with **made-up data** (name, number and address are invented).
It is not a real ID and exists only so the "Scan IC" feature can be tried without using a real person's card.

Push it to the phone's gallery, then use Capture > From gallery:

    adb push docs/sample-ic/sample_mykad_FAKE.png /sdcard/Pictures/
