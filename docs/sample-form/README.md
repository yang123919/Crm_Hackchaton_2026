# Sample forms for testing the form scanner

Both images are drawn with **made-up data**. They exist only so "Scan form" can be tried without a real customer's form.

- `sample_form_printed_FAKE.png`: printed answers (what an office-printed or typed form looks like).
- `sample_form_handwriting_style_FAKE.png`: answers in a handwriting-style font. Real handwriting is harder to read than this.
